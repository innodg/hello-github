# STEP 01: Git 설치 안내

## 개요
Git은 버전 관리 시스템으로, 코드의 변경 이력을 추적하고 관리합니다.

## 설치 방법

### Windows
다음 링크에서 Git을 다운로드하세요: https://git-scm.com/download/win

### macOS
다음 링크에서 Git을 다운로드하세요: https://git-scm.com/download/mac

### Linux
터미널에서 다음 명령어를 실행하세요:
```bash
sudo apt-get install git
```

## 설치 확인
설치가 완료되었는지 확인하려면 터미널/명령 프롬프트에서 다음 명령어를 입력하세요:
```bash
git --version
```

정상적으로 설치되었다면 Git의 버전 정보가 표시됩니다.
