# STEP 03: GitHub Desktop 설치 안내

## 🎯 이 단계에서 배우는 것
깃허브 데스크탑(GitHub Desktop)이라는 프로그램을 설치합니다. 이 프로그램은 깃(Git)을 쉽게 사용할 수 있도록 만든 도구입니다.

## 📚 깃허브 데스크탑(GitHub Desktop)이 뭔가요?
깃허브 데스크탑(GitHub Desktop)은 깃(Git)을 사용할 때 **복잡한 명령어를 입력하지 않고도** 쉽게 사용할 수 있도록 만들어진 프로그램입니다.
마치 엑셀을 사용할 때 버튼을 클릭해 엑셀 기능들을 사용하는 것처럼, 깃허브 데스크탑(GitHub Desktop)도 버튼을 클릭하면 쉽게 깃을 사용할 수 있습니다.

> [!TIP]
> 깃허브 데스크탑(GitHub Desktop) = 깃(Git)을 쉽게 사용할 수 있는 프로그램 🖥️

> [!IMPORTANT]
> 🍎 **macOS 사용자**(맥북, 아이맥 등)는 [macOS용 STEP 03 문서](/docs/macos/step03-github-desktop-installation.md)로 이동합니다.

## 💾 깃허브 데스크탑 설치하기

### 1단계: 깃허브 데스크탑 다운로드

인터넷 브라우저(Microsoft Edge, Chrome 등)를 열어서 주소창에 `https://desktop.github.com/download/`를 입력합니다.

![주소 입력](/docs/images/step-03-image-01.png)

아래 사진 속 화살표 방향의 버튼을 찾아서 클릭합니다.

![깃허브 데스크탑 Windows 다운로드](/docs/images/step-03-image-02.png)

### 2단계: 설치 프로그램 실행

다운로드를 완료하면, 다운로드 폴더에서 **`GitHubDesktopSetup-x64.exe` 또는 비슷한 이름의 파일**을 찾은 후 더블클릭해서 실행합니다.

![Windows 다운로드 폴더에서 깃허브 데스크탑 설치 파일 찾기](/docs/images/step-03-image-03.png)

### 3단계: 깃허브 데스크탑 실행하기

깃허브 데스크탑 실행을 위해 잠시 기다립니다. 설치가 끝나면 깃허브 데스크탑을 자동으로 실행해 화면을 보여줍니다.

> [!TIP]
> 만약 자동으로 실행되지 않으면, 다음 단계를 수행합니다 :
> 1. **윈도우 시작 메뉴**를 클릭합니다.
> 2. 검색칸("프로그램 및 파일 검색" 부분)을 클릭한 후, "GitHub Desktop"을 검색합니다.
> 3. **GitHub Desktop**을 클릭해서 실행합니다.

### 4단계: 깃허브 데스크탑에서 깃허브 계정으로 로그인하기

`Sign in to GitHub.com`이라는 버튼을 찾아 클릭합니다.

![깃허브 데스크탑 첫 실행 화면](/docs/images/step-03-image-04.png)


#### 로그인 진행하기

버튼을 클릭하면 인터넷 브라우저(Chrome, Microsoft Edge 등)가 자동으로 열립니다.
깃허브 웹사이트의 **로그인 페이지**가 나타나면, 우리가 STEP 02에서 만든 **이메일**과 **비밀번호**를 입력합니다.

![깃허브 웹사이트 로그인 페이지](/docs/images/step-03-image-05.png)
처음으로 깃허브 데스크탑에서 로그인하는 경우, "Authorize GitHub Desktop"이라는 페이지가 나타납니다. 이 페이지에서 `Continue` 버튼을 클릭합니다.

![Authorize GitHub Desktop](/docs/images/step-03-image-06.png)
이어서 "Authorize desktop" 버튼을 클릭합니다.

![Authorize desktop 버튼](/docs/images/step-03-image-07.png)
깃허브 데스크탑으로 돌아가면 "Configure Git"이라는 글씨가 보입니다. **아무것도 건드리지 않고** "Finish" 버튼을 클릭합니다.

![Configure Git 화면](/docs/images/step-03-image-08.png)

## ✅ 완료!
