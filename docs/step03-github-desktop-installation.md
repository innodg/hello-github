# STEP 03: GitHub Desktop 설치 안내

## 🎯 이 단계에서 배우는 것
GitHub Desktop이라는 프로그램을 설치합니다. 이 프로그램은 Git을 쉽게 사용할 수 있도록 만든 도구입니다.

## 📚 GitHub Desktop이 뭔가요?
GitHub Desktop은 Git을 사용할 때 **복잡한 명령어를 입력하지 않아도 되도록** 만들어진 프로그램입니다.
마치 엑셀을 사용할 때 버튼을 클릭하는 것처럼, GitHub Desktop도 버튼을 클릭하면 쉽게 작동합니다.

> GitHub Desktop = Git을 쉽게 사용할 수 있는 프로그램 🖥️

## 💾 GitHub Desktop 설치하기

### 1단계: GitHub Desktop 다운로드

1. 인터넷 브라우저(Chrome, Microsoft Edge 등)를 열어서 이 주소로 이동하세요:
   ```
   https://desktop.github.com/download/
   ```
2. 화면에서 큰 **"Download for Windows"** 버튼을 찾아서 클릭하세요.

   ![GitHub Desktop Windows 다운로드](/images/step03/1-windows-download.png)

### 2단계: 설치 프로그램 실행

1. 다운로드가 완료되면, 다운로드 폴더에서 **`GitHubDesktopSetup-x64.exe` 또는 비슷한 이름의 파일**을 찾으세요.
2. 그 파일을 **더블클릭**해서 실행하세요.

   ![Windows 다운로드 폴더에서 GitHub Desktop 설치 파일 찾기](/images/step03/2-download-folder.png)

### 3단계: GitHub Desktop 실행하기

> 🥕 GitHub Desktop은 자동으로 설치되고 실행됩니다. **잠시 기다려주세요!**

> 🥕 만약 자동으로 실행되지 않으면
> 1. **윈도우 시작 메뉴**를 클릭하세요.
> 2. "프로그램 및 파일 검색" 부분을 클릭한 후, "GitHub Desktop"을 검색하세요.
> 3. **GitHub Desktop**을 클릭해서 실행하세요.

### 4단계: GitHub Desktop에서 GitHub 계정으로 로그인하기

"Sign in to GitHub.com"이라는 파란색 버튼을 찾아 클릭합니다.

![GitHub Desktop 첫 실행 화면](/images/step03/3-first-run.png)


#### 로그인 진행하기

1. 버튼을 클릭하면 인터넷 브라우저(Chrome, Microsoft Edge 등)가 자동으로 열립니다.
2. GitHub 웹사이트의 **로그인 페이지**가 나타나면, 우리가 STEP 02에서 만든 **이메일**과 **비밀번호**를 입력하세요.

   ![GitHub 웹사이트 로그인 페이지](/images/step03/4-github-login.png)
3. 처음으로 GitHub Desktop에서 로그인하는 경우, "Authorize GitHub Desktop"이라는 페이지가 나타납니다. 이 페이지에서 "Continue" 버튼을 클릭합니다.

   ![Authorize GitHub Desktop](/images/step03/5-authorize-desktop.png)
4. 이어서 "Authorize desktop" 버튼을 클릭합니다.

   ![Authorize desktop 버튼](/images/step03/6-authorize-desktop-button.png)
5. GitHub Desktop으로 돌아가면 "Configure Git"이라는 글씨가 보입니다. 아무것도 입력하지 말고 "Finish" 버튼을 클릭합니다.

   ![Configure Git 화면](/images/step03/7-configure-git.png)

## ✅ 완료!
아래와 같은 화면이 보이면 성공적으로 GitHub Desktop에 로그인한 것입니다! 🎉

![GitHub Desktop 로그인 성공 후 화면](/images/step03/8-login-success.png)
