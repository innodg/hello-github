# STEP 08: Pull해서 GitHub 변경 내용 가져오기

## 🎯 이 단계에서 배우는 것
GitHub 웹사이트에서 수정한 내용을 내 컴퓨터의 GitHub Desktop으로 가져오는 방법입니다. Pull을 하면 온라인 저장소에서 바뀐 내용이 내 컴퓨터에도 반영됩니다.

## 📚 풀(Pull)이 뭔가요?
풀(Pull)은 GitHub의 원격 저장소에 있는 최신 변경 내용을 내 컴퓨터로 가져오는 작업입니다.

## 🔽 GitHub에서 수정하고 풀하기

### 1단계: GitHub 웹사이트 접속
웹 브라우저에서 https://github.com 에 접속합니다.

### 2단계: 저장소 열기
본인의 저장소로 들어갑니다.  
예) `my-first-project`

### 3단계: 수정할 파일 선택
수정하고 싶은 파일을 클릭합니다.

### 4단계: 파일 수정하기

![pull 이미지](images/step-08-image-001.png)

파일 오른쪽 위의 연필 모양 아이콘(`Edit this file`)을 클릭합니다.

파일 내용을 원하는 대로 수정합니다.

### 5단계: 웹에서 커밋하기

![pull 이미지](images/step-08-image-002.png)

수정이 끝나면 `Commit changes...` 버튼을 클릭합니다

![pull 이미지](images/step-08-image-003.png)

커밋 메세지를 작성한 후, 다시 `Commit changes` 버튼을 클릭하여 커밋합니다.

### 6단계: GitHub Desktop으로 돌아오기
GitHub Desktop을 엽니다.

### 7단계: Pull 버튼 클릭

![pull 이미지](images/step-08-image-004.png)

조금전 GitHub 웹에서 했던 변경 사항이 감지되면 `Pull origin` 버튼을 클릭합니다.

![pull 이미지](images/step-08-image-005.png)

좌측 `History` 탭을 통해 변경 사항이 내 컴퓨터에 반영된 것을 확인할 수 있습니다.

## ✅ 완료!
축하합니다! 🎉 GitHub 웹사이트에서 수정한 내용을 커밋하고, GitHub Desktop으로 성공적으로 가져왔습니다!

이제 우리는 GitHub 웹사이트에서 파일을 수정한 뒤, 커밋으로 변경 내용을 기록하고, 풀을 통해 그 내용을 내 컴퓨터에 반영하는 흐름까지 완성했습니다.

다음 단계에서는 이슈(Issue)를 생성하면서, 해야 할 일이나 수정할 내용을 GitHub에서 정리하고 관리하는 방법을 배워볼 거예요.
