# STEP 04: GitHub 저장소 생성

## 개요
저장소(Repository)는 프로젝트의 모든 파일과 변경 이력을 저장하는 공간입니다.

## 저장소 생성 방법

### 1단계: 프로필 메뉴 열기
GitHub에 로그인 후, 우측 상단의 프로필 아이콘을 클릭합니다.

### 2단계: New repository 선택
드롭다운 메뉴에서 "New repository"를 선택합니다.

### 3단계: 저장소 정보 입력
- **Repository name**: 만들 저장소의 이름을 입력합니다. (예: my-first-project)
- **Description**: 저장소에 대한 설명을 입력합니다. (선택사항)
- **Public/Private**: 공개 또는 비공개 선택
- **Initialize this repository with**: README 파일을 포함할지 선택

### 4단계: Create repository 클릭
"Create repository" 버튼을 클릭하여 저장소를 생성합니다.

## 저장소 생성 완료
저장소가 성공적으로 생성되었습니다!
