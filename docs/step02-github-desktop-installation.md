# STEP 02: GitHub Desktop 설치 안내

## 개요
GitHub Desktop은 GUI 기반의 Git 클라이언트로, 커맨드 라인 없이 쉽게 Git을 사용할 수 있습니다.

## 설치 방법

### 다운로드
다음 링크에서 GitHub Desktop을 다운로드하세요: https://desktop.github.com/

### 설치 과정
1. 다운로드한 설치 파일을 실행합니다.
2. 화면에 표시되는 설치 마법사를 따릅니다.
3. 설치가 완료될 때까지 기다립니다.

## 실행
설치가 완료되면 GitHub Desktop 애플리케이션을 실행합니다.
