# STEP 09: 이슈 생성하기

## 🎯 이 단계에서 배우는 것
해야 할 일이나 수정할 내용을 GitHub에 정리해서 남기는 방법입니다. 이슈(Issue)를 만들면 작업을 더 체계적으로 관리하고, 끝난 일은 닫아서 구분합니다.

## 📚 이슈(Issue)가 뭔가요?
이슈(Issue)는 버그 보고, 기능 제안, 작업 할당 등을 관리하는 도구입니다.

## 💡 이슈 생성하기

### 1단계: 저장소 접속
GitHub에서 본인의 저장소에 접속합니다.

### 2단계: 이슈 생성 시작
![Issue 이미지](images/step-09-image-01.png)

저장소 페이지의 `Issues` 탭을 클릭합니다.

`New issue` 버튼을 클릭합니다.

### 3단계: 이슈 작성
![Issue 이미지](images/step-09-image-02.png)

- **Title**: 이슈의 제목을 입력합니다.
- **Description**: 이슈에 대한 설명을 상세히 작성합니다.

#### 예제:
- Title: "프로필 사진 추가"
- Description: "자기소개 페이지에 프로필 사진을 추가합니다."

### 4단계: 이슈 생성
![Issue 이미지](images/step-09-image-02.png)

`Create` 버튼을 클릭하여 이슈를 생성합니다.

## 이슈 생성 완료
![Issue 이미지](images/step-09-image-03.png)

성공적으로 이슈를 생성했습니다!

![Issue 이미지](images/step-09-image-04.png)

생성된 이슈를 확인합니다.

### 5단계: 이슈 닫기
![Issue 이미지](images/step-09-image-05.png)

완료한 이슈를 선택해 닫습니다.

우측 하단에 `Close issue` 버튼을 클릭합니다.

### 6단계: 이슈 닫기 완료

![Issue 이미지](images/step-09-image-06.png)

이슈가 닫혔습니다.

![Issue 이미지](images/step-09-image-07.png)

`Closed` 탭에서 닫힌 이슈들을 확인합니다.
