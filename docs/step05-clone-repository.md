# STEP 05: GitHub Desktop으로 저장소 클론

## 개요
클론(Clone)은 GitHub의 저장소를 로컬 컴퓨터에 복사하는 작업입니다.

## 클론 방법

### 1단계: GitHub Desktop 실행
GitHub Desktop을 실행합니다.

### 2단계: GitHub 계정 로그인
GitHub Desktop을 처음 실행할 경우, GitHub 계정으로 로그인합니다.

### 3단계: 저장소 클론
메뉴의 "File" > "Clone Repository"를 선택합니다.

### 4단계: 저장소 선택
- **URL**: 클론할 저장소의 URL을 입력하거나, 선택합니다.
- **Local Path**: 파일을 저장할 로컬 경로를 선택합니다.

### 5단계: Clone 버튼 클릭
"Clone" 버튼을 클릭하여 저장소를 다운로드합니다.

## 클론 완료
저장소가 로컬 컴퓨터에 성공적으로 복사되었습니다!
