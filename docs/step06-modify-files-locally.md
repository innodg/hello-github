# STEP 06: 로컬에서 파일 수정 또는 생성

## 개요
로컬에서 파일을 수정하거나 새로운 파일을 생성할 수 있습니다.

## 파일 작업

### 1단계: 폴더 열기
GitHub Desktop에서 "Show in Explorer" (또는 "Open in Finder")를 클릭하여 폴더를 엽니다.

### 2단계: 파일 편집
텍스트 에디터나 IDE를 사용하여 파일을 편집합니다.
또는 새로운 파일을 생성합니다.

### 예제
`hello.txt` 파일을 생성하고 다음 내용을 입력합니다:
```
Hello, GitHub!
```

## 변경 사항 확인
파일 저장 후, GitHub Desktop에서 변경 사항이 자동으로 감지됩니다.
