# STEP 03: GitHub 가입

## 개요
GitHub는 코드 저장소를 호스팅하고 협업을 가능하게 하는 플랫폼입니다.

## 가입 절차

### 1단계: GitHub 방문
https://github.com 에 접속합니다.

### 2단계: Sign up 클릭
페이지 우측 상단의 "Sign up" 버튼을 클릭합니다.

### 3단계: 정보 입력
- 이메일 주소 입력
- 비밀번호 설정
- 사용자명 설정

### 4단계: 이메일 인증
입력하신 이메일로 인증 코드가 발송됩니다. 인증 코드를 입력하여 이메일을 확인합니다.

### 5단계: 가입 완료
모든 단계를 완료하면 GitHub 계정이 생성됩니다.
