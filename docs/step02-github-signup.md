# STEP 02: GitHub 가입

## 🎯 이 단계에서 배우는 것
깃허브(GitHub)에 새로운 계정을 만드는 방법입니다. 깃허브(GitHub)는 우리가 만든 파일들을 인터넷에 저장하고 공유할 수 있는 사이트입니다.

## 📚 깃허브(GitHub)가 뭔가요?
깃허브(GitHub)는 마치 OneDrive 또는 Google Drive처럼 우리의 파일을 인터넷에 저장할 수 있는 곳입니다.
하지만 OneDrive 또는 Google Drive와 달리, 깃허브(GitHub)는 깃(Git)이라는 도구와 함께 작동하기 때문에 파일의 변화를 더 잘 기록할 수 있습니다.

> [!TIP]
> 깃허브(GitHub) = 파일을 저장하는 클라우드 저장소(Repository) (OneDrive, Google Drive처럼)

## 📝 깃허브 계정 만들기

### 1단계: 깃허브 웹사이트 방문하기

인터넷 브라우저(Microsoft Edge, Chrome 등)를 열어서 주소창에 `https://github.com`를 입력합니다.

![깃허브 공식 웹사이트 주소 입력](/docs/images/step-02-image-01.png)

깃허브 기본 화면이 보입니다.

![깃허브 메인 페이지](/docs/images/step-02-image-02.png)

### 2단계: 가입 버튼 클릭하기

페이지의 **오른쪽 위에** `Sign up`이라는 버튼을 찾아 클릭합니다.

![깃허브 메인 페이지 우측 상단의 Sign up 버튼](/docs/images/step-02-image-03.png)

### 3단계: 이메일 입력하기

가입 페이지가 열리면 **이메일 주소**를 입력합니다.

![깃허브 가입 페이지 - 이메일 입력창](/docs/images/step-02-image-04.png)

### 4단계: 비밀번호 설정하기

비밀번호는 **최소 15자 이상**이거나, **최소 8자 이상이면서 숫자와 영문 소문자를 포함**해야 합니다.

![깃허브 가입 페이지 - 비밀번호 입력창](/docs/images/step-02-image-05.png)

### 5단계: 사용자명 설정하기

사용자명은 영숫자(알파벳과 숫자) 또는 하이픈(-)만 포함할 수 있으며, 하이픈으로 시작하거나 끝날 수 없습니다.

> [!WARNING]
> 다른 사람들이 본인의 사용자명을 볼 수 있습니다. 개인정보(이름, 전화번호 등)를 노출하지 않도록 주의하고, 장난스러운 표현, 혐오 표현, 저작권 문제 가능성이 있는 표현은 피해야 합니다.

![깃허브 가입 페이지 - 사용자명 입력창](/docs/images/step-02-image-06.png)

### 6단계 : 지역 설정

기본적으로는 변경할 필요가 없지만, 만약 `Your Country/Region` 부분이 `Korea, South`가 아니라면 `Korea, South`를 선택합니다.

> ![깃허브 가입 페이지 - 국가 선택 부분](/docs/images/step-02-image-07.png)

### 7단계: 계정 생성

`Create account >` 버튼을 클릭합니다.

![깃허브 가입 페이지 - Create account 버튼](/docs/images/step-02-image-08.png)

> [!NOTE]
> 계정 생성 과정에서 아래와 같은 추가 인증 화면이 나타날 수 있습니다. 화면의 안내에 따라 인증을 완료합니다.
>
> ![캡챠 인증 화면](/docs/images/step-02-image-09.png)

> [!TIP]
> 신규 계정 생성 시 AI 봇 방지를 위한 시각 퍼즐 및 오디오 퍼즐 인증 절차가 추가로 있을 수 있습니다.
> [시각 퍼즐 및 오디오 퍼즐 인증 절차 가이드](https://www.youtube.com/watch?v=DSDz3fEuQRw)를 참고하시면 됩니다.

### 8단계: 이메일 확인

깃허브가 우리의 이메일로 **확인 코드**를 보냅니다.

우리가 입력한 이메일의 **받은편지함**을 확인합니다.
`🚀 Your GitHub launch code` 또는 비슷한 제목의 이메일을 찾습니다.

![받은편지함](/docs/images/step-02-image-10.png)

이메일 **확인 코드**를 복사해서 깃허브 페이지에 붙여넣습니다.

![수신 이메일 코드 화면](/docs/images/step-02-image-11.png)

![코드 입력 화면](/docs/images/step-02-image-12.png)

> [!TIP]
> 만약 이메일을 받지 못했다면, 스팸 메일함(스팸함)을 확인해봅니다. 때로는 깃허브의 이메일을 스팸으로 분류하기도 합니다.

## 깃허브 로그인하기

깃허브 계정 생성을 완료하면, 깃허브 홈페이지로 이동합니다. 이제, 우리가 만든 계정으로 로그인합니다.

![깃허브 로그인 성공 후 메인 페이지](/docs/images/step-02-image-13.png)

### 1단계 : 로그인 버튼 클릭하기

페이지의 **오른쪽 위에** `Sign in`이라는 버튼을 찾아 클릭합니다.

![깃허브 로그인 페이지 우측 상단의 Sign in 버튼](/docs/images/step-02-image-14.png)

### 2단계 : 이메일과 비밀번호 입력하기

로그인 페이지에서 우리가 가입할 때 사용한 **이메일 주소**와 **비밀번호**를 입력합니다.

![깃허브 로그인 페이지 - 이메일과 비밀번호 입력창](/docs/images/step-02-image-15.png)

### 3단계 : 로그인 버튼 클릭하기

`Sign in` 버튼을 클릭합니다.

![깃허브 로그인 페이지 - Sign in 버튼](/docs/images/step-02-image-16.png)

## ✅ 완료!
축하합니다! 🎉 깃허브 계정을 성공적으로 만들었습니다!

아래와 같은 화면이 보인다면 로그인에 성공하였습니다.
