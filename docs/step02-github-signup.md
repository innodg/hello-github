# STEP 02: GitHub 가입

## 🎯 이 단계에서 배우는 것
GitHub에 새로운 계정을 만드는 방법입니다. GitHub는 우리가 만든 파일들을 인터넷에 저장하고 공유할 수 있는 사이트입니다.

## 📚 GitHub가 뭔가요?
GitHub는 마치 OneDrive 또는 Google Drive처럼 우리의 파일을 인터넷에 저장할 수 있는 곳입니다.
하지만 OneDrive 또는 Google Drive와 달리, GitHub는 **Git**이라는 도구와 함께 작동하기 때문에 파일의 변화를 더 잘 기록할 수 있습니다.

> [!TIP]
> GitHub = 파일을 저장하는 클라우드 저장소 (OneDrive, Google Drive처럼)

## 📝 GitHub 계정 만들기

### 1단계: GitHub 웹사이트 방문하기

1. 인터넷 브라우저(Microsoft Edge, Chrome 등)를 열어서 주소창에 `https://github.com`를 입력하세요.

   ![GitHub 공식 웹사이트 주소 입력](/docs/images/step02/step-02-image-00.png)

2. GitHub의 메인 페이지가 보일 거예요.

   ![GitHub 메인 페이지](/docs/images/step02/step-02-image-01.png)

### 2단계: 가입 버튼 클릭하기

페이지의 **오른쪽 위에** "Sign up"이라는 버튼을 찾아 클릭합니다.

![GitHub 메인 페이지 우측 상단의 Sign up 버튼](/docs/images/step02/step-02-image-02.png)

### 3단계: 이메일 입력하기

가입 페이지가 열리면 **이메일 주소**를 입력하세요.

![GitHub 가입 페이지 - 이메일 입력창](/docs/images/step02/step-02-image-03.png)

### 4단계: 비밀번호 설정하기

비밀번호는 **최소 15자 이상**이거나, **최소 8자 이상이면서 숫자와 영문 소문자를 포함**해야 합니다.

![GitHub 가입 페이지 - 비밀번호 입력창](/docs/images/step02/step-02-image-04.png)

### 5단계: 사용자명 설정하기

사용자명은 영숫자(알파벳과 숫자) 또는 하이픈(-)만 포함할 수 있으며, 하이픈으로 시작하거나 끝날 수 없습니다.

> [!WARNING]
> 사용자명은 다른 사람들에게 공개됩니다. 개인정보(이름, 전화번호 등)가 노출되지 않도록 주의하고, 장난스러운 표현, 혐오 표현, 저작권 문제가 될 수 있는 표현은 사용하지 마세요.

![GitHub 가입 페이지 - 사용자명 입력창](/docs/images/step02/step-02-image-05.png)

### 6단계 : 지역 설정

기본적으로는 변경할 필요가 없지만, 만약 "Your Country/Region" 부분이 "Korea, South"가 아니라면 "Korea, South"를 선택합니다.

> ![GitHub 가입 페이지 - 국가 선택 부분](/docs/images/step02/step-02-image-06.png)

### 7단계: 계정 생성

`Create account >` 버튼을 클릭합니다.

![GitHub 가입 페이지 - Create account 버튼](/docs/images/step02/step-02-image-07.png)

> [!NOTE]
> 계정 생성 과정에서 아래와 같은 추가 인증 화면이 나타날 수 있습니다. 화면의 안내에 따라 인증을 완료하세요.
>
> ![캡챠 인증 화면](/docs/images/step02/step-02-image-08.png)

### 8단계: 이메일 확인

GitHub가 우리의 이메일로 **확인 코드**를 보냅니다.

1. 우리가 입력한 이메일의 **받은편지함**을 확인하세요.
2. "🚀 Your GitHub launch code" 또는 비슷한 제목의 이메일을 찾으세요.

   ![받은편지함](/docs/images/step02/step-02-image-09.png)

3. 이메일 **확인 코드**를 복사해서 GitHub 페이지에 붙여넣으세요.

   ![수신 이메일 코드 화면](/docs/images/step02/step-02-image-10.png)
   
   ![코드 입력 화면](/docs/images/step02/step-02-image-11.png)

> [!TIP]
> 만약 이메일을 받지 못했다면, **스팸 메일함(스팸함)**을 확인해보세요. 때로는 GitHub의 이메일이 스팸으로 분류될 수 있습니다.

## GitHub 로그인하기

GitHub 계정 생성을 완료하면, GitHub 홈페이지로 이동합니다. 이제, 우리가 만든 계정으로 로그인합니다.

![GitHub 로그인 성공 후 메인 페이지](/docs/images/step02/step-02-image-12.png)

### 1단계 : 로그인 버튼 클릭하기

페이지의 **오른쪽 위에** "Sign in"이라는 버튼을 찾아 클릭합니다.

![GitHub 로그인 페이지 우측 상단의 Sign in 버튼](/docs/images/step02/step-02-image-13.png)

### 2단계 : 이메일과 비밀번호 입력하기

로그인 페이지에서 우리가 가입할 때 사용한 **이메일 주소**와 **비밀번호**를 입력하세요.

![GitHub 로그인 페이지 - 이메일과 비밀번호 입력창](/docs/images/step02/step-02-image-14.png)

### 3단계 : 로그인 버튼 클릭하기

"Sign in" 버튼을 클릭합니다.

![GitHub 로그인 페이지 - Sign in 버튼](/docs/images/step02/step-02-image-15.png)

## ✅ 완료!
축하합니다! 🎉 GitHub 계정이 성공적으로 만들어졌습니다!

아래와 같은 화면이 보인다면 로그인에 성공한 것입니다.
