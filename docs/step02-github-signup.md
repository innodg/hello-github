# STEP 02: GitHub 가입

## 🎯 이 단계에서 배우는 것
GitHub에 새로운 계정을 만드는 방법입니다. GitHub는 우리가 만든 파일들을 인터넷에 저장하고 공유할 수 있는 사이트입니다.

## 📚 GitHub가 뭔가요?
GitHub는 마치 구글 드라이브처럼 우리의 파일을 인터넷에 저장할 수 있는 곳입니다.
하지만 Google Drive와 달리, GitHub는 **Git**이라는 도구와 함께 작동하기 때문에 파일의 변화를 더 잘 기록할 수 있습니다.

> **쉽게 말하면**: GitHub = 파일을 저장하는 클라우드 저장소 (Google Drive처럼) ☁️

## 📝 GitHub 계정 만들기

### 1단계: GitHub 웹사이트 방문하기

1. 인터넷 브라우저를 열어서 이 주소로 이동하세요:
   ```
   https://github.com
   ```

2. GitHub의 메인 페이지가 보일 거예요.
   ![GitHub 메인 페이지](/images/step02/1-main-page.png)

### 2단계: 가입 버튼 클릭하기

페이지의 **오른쪽 위에** "Sign up"이라는 버튼을 찾아 클릭합니다.

![GitHub 메인 페이지 우측 상단의 Sign up 버튼](/images/step02/2-signup-button.png)

### 3단계: 이메일 입력하기

가입 페이지가 열리면 **이메일 주소**를 입력하세요.

![GitHub 가입 페이지 - 이메일 입력창](/images/step02/3-email-input.png)

### 4단계: 비밀번호 설정하기

비밀번호는 **최소 15자 이상**이거나, **최소 8자 이상이면서 숫자와 영어 소문자를 포함**해야 합니다.

![GitHub 가입 페이지 - 비밀번호 입력창](/images/step02/4-password-input.png)

### 5단계: 사용자명 설정하기

사용자명은 영숫자(알파벳과 숫자) 또는 하이픈(-)만 포함할 수 있으며, 하이픈으로 시작하거나 끝날 수 없습니다.

![GitHub 가입 페이지 - 사용자명 입력창](/images/step02/5-username-input.png)

### 6단계 : 지역 설정

"Your Country/Region" 부분이 "Korea, South"가 아니라면 "Korea, South"를 선택합니다.

> ![GitHub 가입 페이지 - 국가 선택 부분](/images/step02/6-country-region.png)

### 7단계: 계정 생성

`Create account >` 버튼을 클릭합니다.

![GitHub 가입 페이지 - Create account 버튼](/images/step02/7-create-account.png)

### 8단계: 이메일 확인

GitHub가 우리의 이메일로 **확인 코드**를 보냅니다.
1. 우리가 입력한 이메일의 **받은편지함**을 확인하세요.
2. "🚀 Your GitHub launch code" 또는 비슷한 제목의 이메일을 찾으세요.

   ![받은편지함](/images/step02/8-received-email-list.png)
3. 이메일 **확인 코드**를 복사해서 GitHub 페이지에 붙여넣으세요.

   ![수신 이메일 코드 화면](/images/step02/9-email-verification.png)
   
   ![코드 입력 화면](/images/step02/10-email-code-input.png)

## GitHub 로그인하기

GitHub 계정 생성을 완료하면, GitHub 홈페이지로 이동합니다. 이제, 우리가 만든 계정으로 로그인합니다.

![GitHub 로그인 성공 후 메인 페이지](/images/step02/11-signup-success.png)

### 1단계 : 로그인 버튼 클릭하기

페이지의 **오른쪽 위에** "Sign in"이라는 버튼을 찾아 클릭합니다.

![GitHub 로그인 페이지 우측 상단의 Sign in 버튼](/images/step02/12-signin-button.png)

### 2단계 : 이메일과 비밀번호 입력하기

로그인 페이지에서 우리가 가입할 때 사용한 **이메일 주소**와 **비밀번호**를 입력하세요.

![GitHub 로그인 페이지 - 이메일과 비밀번호 입력창](/images/step02/13-login-inputs.png)

### 3단계 : 로그인 버튼 클릭하기

"Sign in" 버튼을 클릭합니다.

![GitHub 로그인 페이지 - Sign in 버튼](/images/step02/14-signin-button.png)

## ✅ 완료!
축하합니다! 🎉 GitHub 계정이 성공적으로 만들어졌습니다!

아래와 같은 화면이 보인다면 로그인에 성공한 것입니다.

![GitHub 로그인 성공 후 메인 페이지](/images/step02/15-login-success.png)
