# STEP 08: Push해서 GitHub으로 올리기

## 🎯 이 단계에서 배우는 것
내 컴퓨터에서 작업한 내용을 GitHub 사이트에 올리는 방법입니다. Push를 하면 로컬에서 만든 변경 사항이 온라인 저장소에도 반영됩니다.

## 📚 푸시(Push)가 뭔가요?
푸시(Push)는 로컬에서 커밋한 변경 사항을 GitHub의 원격 저장소에 업로드하는 작업입니다.

## 🔼 푸시하기

### 1단계: Push 버튼 클릭
![push 이미지](images/step-08-image-01.png)

GitHub Desktop의 우측 상단에 있는 `Push origin` 버튼을 클릭합니다.

### 2단계: GitHub 웹사이트에서 확인
웹 브라우저에서 https://github.com 에 접속합니다.

### 3단계: 저장소 확인
본인의 저장소로 접속합니다.
예) my-first-project

### 4단계: 새로고침
![push 이미지](images/step-08-image-02.png)

페이지를 새로고침하여 방금 Push한 파일이 반영되었는지 확인합니다.

커밋 메시지도 잘 작성되었는지 같이 확인합니다.

## 성공!
업로드한 파일이 GitHub 웹사이트에 보입니다.
