# STEP 07: GitHub Desktop에서 커밋

## 커밋(Commit)이란?
커밋(Commit)은 변경된 파일을 저장소의 역사에 기록하는 작업입니다.

## 커밋 절차

### 1단계: GitHub Desktop 확인
![GitHubDesktop 변경사항](images/step-07-image-01.png)
GitHub Desktop을 열어 파일의 변경 사항을 확인합니다.
</br></br>

### 2단계: 파일 선택
![GitHubDesktop 변경사항](images/step-07-image-02.png)
커밋할 파일을 선택합니다. (기본적으로 모든 변경 사항이 선택됩니다.)
</br></br>

### 3단계: 커밋 메시지 작성
![GitHubDesktop 변경사항](images/step-07-image-03.png)

좌측 아래의 필드에 커밋 메시지를 작성합니다.

어떤 수정사항이 있었는지, 그 수정사항과 자세한 설명을 작성합니다.

**좋은 커밋 메시지 예시:**
- "파일 추가"
- "버그 수정"
- "기능 추가"

#### 예제
```
간단한 자기소개 작성
```
```
이름, 학교, 잘하는 일을 작성하였습니다.
```
</br>

### 4단계: Commit 버튼 클릭
![GitHubDesktop 변경사항](images/step-07-image-03.png)

`Commit to main` 버튼을 클릭하여 커밋합니다.
</br></br>

## 커밋 완료
변경 사항이 저장소의 역사에 기록되었습니다!
