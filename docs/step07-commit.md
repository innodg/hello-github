# STEP 07: GitHub Desktop에서 커밋

## 개요
커밋(Commit)은 변경된 파일을 저장소의 역사에 기록하는 작업입니다.

## 커밋 절차

### 1단계: GitHub Desktop 확인
GitHub Desktop을 열어 변경된 파일을 확인합니다.

### 2단계: 파일 선택
커밋할 파일을 선택합니다. (기본적으로 모든 변경 사항이 선택됨)

### 3단계: 커밋 메시지 작성
좌측 아래의 "Summary" 필드에 커밋 메시지를 작성합니다.

**좋은 커밋 메시지 예시:**
- "파일 추가"
- "버그 수정"
- "기능 추가"

### 4단계: Commit 버튼 클릭
"Commit to main" 버튼을 클릭하여 커밋합니다.

## 커밋 완료
변경 사항이 저장소의 역사에 기록되었습니다!
