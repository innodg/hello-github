# hello-github

## 📚 개요

초중고 학생들을 위한 GitHub 입문 가이드입니다. 
Git 기본 개념부터 GitHub를 통한 협업까지 단계별로 학습할 수 있습니다.

> [!NOTE]
> **화면 구성(버튼 및 글자 위치, 색상 등)은 시간이 지남에 따라 달라질 수 있습니다.** 만약 문서 사진과 사용자의 실제 진행 화면이 다르다면, 당황하지 말고 문서와 비슷한 내용의 버튼이나 글자를 찾아서 진행합니다.
